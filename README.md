# Deemo

## Project structure

- [`frontend/`](./frontend/) - Flutter application for Android, iOS, desktop,
  and web.
- [`backend/`](./backend/) - Python FastAPI service.

## Run the frontend

```powershell
cd frontend
flutter pub get
flutter run
```

## Run the backend

See [`backend/README.md`](./backend/README.md) for setup and local
development instructions.
